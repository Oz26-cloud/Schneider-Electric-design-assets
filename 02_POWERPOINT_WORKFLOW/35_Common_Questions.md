## 7 QUESTIONS YOUR TEAM ASKS MOST

Answers to the questions that come up while designing SE presentations.

---

## Q1: "WHICH TEMPLATE SHOULD I USE?"

**Answer:** See **24_Template_Selection_Guide.md** for full decision tree.

**Quick answer:**
- **Sales pitch?** → White template (professional, safe)
- **Executive presentation?** → Dark Green template (premium, authority)
- **Event or keynote?** → Gradient template (maximum visual impact)
- **Training or education?** → White template (clarity, readability)
- **Unsure?** → White template (default, always right)

**Key rule:** Choose ONE template and use it for entire deck. Never mix.

---

## Q2: "WHAT COLOR SHOULD THIS TEXT BE?"

**Answer:** Depends on template and text type.

**By template:**

**White Template:**
- Headings: Dark Green (#0A2F24) or Life Green (#3DCD58)
- Body text: Dark Green
- Accents: Signature Green (#009530)

**Dark Green Template:**
- Headings: White or Light Green (#E7FFD9)
- Body text: Light Green
- Accents: White, Electric Green (#5EFF59)

**Light Green Template:**
- Headings: Dark Green or Signature Green
- Body text: Dark Green
- Accents: Life Green

**Gradient Template:**
- Headings: White or Electric Green
- Body text: White
- Accents: Light Green, Electric Green

**Rule:** Use template's approved colors only. Never invent new colors.

See **05_Color_Palette.md** for full color system.

## Q3: "CAN I USE THIS IMAGE?"

**Answer:** Check these three criteria:

✅ **SOURCE:** Is it from approved folders?
- GitHub repo → 04_ASSETS/16_Illustrations/ (196 approved)
- GitHub repo → 04_ASSETS/14_Icons/ (571 approved)
- SE official photography
- Client-provided brand images

❌ **WHAT TO REJECT:**
- Generic stock photos (dated, clichéd)
- Competitor product images
- Watermarked or low-resolution images
- Unclear or blurry images

✅ **QUALITY:** Is it high-resolution?
- Minimum 1920×1080
- Professional quality
- No watermarks

**Rule:** When in doubt, use SE illustration or icon from assets. Never guess.

See **30_Slide_Image_Showcase.md** for image placement rules.

## Q4: "HOW DO I LAYOUT THIS DATA?"

**Answer:** Choose chart type that matches your data.

**Trends over time** → Line chart
**Comparisons** → Bar chart
**Proportions/percentages** → Pie chart
**Process/steps** → Flowchart or infographic
**Multiple metrics** → Table or dashboard

**Data slide rules:**
- Max 3-4 colors per chart
- All axes labeled
- Data source cited
- Key insight highlighted
- 4.5:1 contrast minimum for text on chart

See **29_Slide_Data_Chart.md** for full data slide guidance.

## Q5: "SHOULD I USE AN ILLUSTRATION OR ICON?"

**Answer:** Use both strategically.

**Use ILLUSTRATIONS when:**
- You need to show a process or workflow
- Humanizing content (show people/characters)
- Breaking up text-heavy sections
- Creating visual interest
- Showing future/vision concepts

**Use ICONS when:**
- Labeling features or benefits
- Supporting bullet points
- Creating step-by-step processes
- Visual hierarchy is needed
- Space is limited

**Remember:**
- Icons: 571 approved in GitHub repo → 04_ASSETS/14_Icons/
- Illustrations: 196 approved in GitHub repo → 04_ASSETS/16_Illustrations/
- Never modify or redraw approved assets

See **14_Icons.md** and **16_Illustrations.md** for specs.

## Q6: "WHAT SIZE SHOULD THE HEADLINE BE?"

**Answer:** 

**Slide titles:** Poppins SemiBold, **22pt maximum**
- Most slides: 18-20pt
- Data slide titles: 16-18pt
- Subheadings: 14-16pt

**Body text:** Poppins Regular, **10pt minimum**
- Most content: 12-14pt
- Never smaller than 10pt (readability minimum)

**Rule of thumb:** If you can't read it from 20 feet away, it's too small.

See **06_Typography_Fonts.md** for complete typography system.

---

## Q7: "HOW MANY LINES OF TEXT PER SLIDE?"

**Answer:** As few as possible.

**By slide type:**

**Title Slide:** 1-2 lines (headline + optional subheadline)
**Content Slide:** Max 5 bullet points, 2-3 lines each
**Data Slide:** Headline + 1-2 sentence insight
**Image Slide:** Headline only (or minimal overlay text)
**Closing Slide:** Headline + contact info

**The rule:** If a bullet point is more than 3 lines, cut it in half.

**Pro tip:** 80% of badly designed slides have too much text. Less is always better.
