# Workflow Overview

**PowerPoint Workflow — Document 23**

---

## THE 8-STEP TAGWW PROCESS

This is the standard workflow for designing Schneider Electric presentations at TAGWW. Follow this structure for every project.

---

## STEP 1: RECEIVE BRIEF

**What to gather from the client:**

- Presentation objective (sales pitch, training, event, strategy?)
- Audience (executives, technicians, partners, investors?)
- Key messages (what 3-5 points must the presentation make?)
- Timeline (deadline for delivery)
- Visual assets (images, logos, data, testimonials available?)
- Existing brand guidelines (any other brand requirements?)
- Presentation type (new deck, update to existing, refresh of old deck?)

**Questions to ask:**
- "What should the audience DO after this presentation?" (Decision? Learn? Be inspired?)
- "Who are the key decision-makers in the room?"
- "What are the top 3 objections we need to address?"
- "How many slides roughly, and how much time?"

**Document:** Client brief in writing before moving to Step 2.

---

## STEP 2: CREATE OUTLINE/STRUCTURE

**Build the presentation skeleton BEFORE designing.**

**Standard Structure (customize as needed):**

```
1. OPENING (1-2 slides)
   - Title/Cover slide
   - Agenda or hook

2. CONTEXT (2-4 slides)
   - Problem or opportunity
   - Market/business context
   - Why this matters

3. SOLUTION (3-6 slides)
   - What SE offers
   - Key differentiators
   - Benefits/outcomes

4. PROOF (2-4 slides)
   - Data/results
   - Case studies/testimonials
   - Evidence

5. NEXT STEPS (1-2 slides)
   - Call to action
   - Timeline
   - Contact/details

6. CLOSING (1 slide)
   - Thank you
   - Final contact info
```

**Customization:**
- Sales pitch: Heavy on problem + solution + proof
- Training: Heavy on process/timeline + examples
- Event: Heavy on inspiration + visuals + CTA
- Strategy: Heavy on data + process + next steps

**Deliverable:** Slide outline (text only, no design yet).

**Time check:** Does the outline fit the timeline? Does it hit all the key messages?

---

## STEP 3: CHOOSE TEMPLATE

**Pick ONE template for the entire presentation. Never mix.**

**Template Options:**

| Template | Background | Logo | Text Color | Best For |
|----------|-----------|------|-----------|----------|
| White | White (#FFFFFF) | SE Signature Green | Dark Green | Clean, professional, minimal |
| Dark Green | SE Dark Green (#0A2F24) | White | Light Green | Premium, executive, bold |
| Light Green | SE Light Green (#E7FFD9) | SE Signature Green | Dark Green | Fresh, modern, approachable |
| Gradient | SE gradient (TL-BR, L-R, T-B, or TR-BL) | White | White or Electric Green | Dynamic, energetic, innovative |

**Selection Guide:**
- **White template:** Most common, safest choice (works for sales, training, events)
- **Dark Green template:** Executive presentations, premium positioning, formal tone
- **Light Green template:** Fresh energy, approachable tone, modern feel
- **Gradient template:** Cutting-edge ideas, innovation focus, high-energy moments

**Decision point:** Template choice determines entire color scheme and mood. Confirm with client before proceeding.

**Deliverable:** Template selection documented and locked in (no changes after Step 4).

---

## STEP 4: BUILD SLIDE DECK (SLIDE BY SLIDE)

**Now design each slide using the approved template.**

**Process for each slide:**

1. Choose slide type (title, content, data, image, etc.)
2. Add headline (20–28pt, Poppins SemiBold)
3. Add body content (8–12pt, Poppins Regular)
4. Choose visual element (image, icon, illustration, oval, or none)
5. Apply colors from approved palette only
6. Check spacing and margins (text stays in safe area)
7. Verify contrast (4.5:1 minimum for all text)
8. Move to next slide

**Per-slide guidelines:**
- See documents 25-34 for each specific slide type
- One idea per slide
- Hierarchy is clear (primary message > supporting info)
- Visual supports message (never decorative)

**Progress check:** After every 3-4 slides, review for consistency.

---

## STEP 5: ADD IMAGERY

**Place all images, icons, illustrations, and visual elements.**

**Image Selection Rules:**

✅ **FROM GitHub repo → 04_ASSETS/ only**
- Icons from 14_Icons/ (571 approved icons)
- Illustrations from 16_Illustrations/ (196 approved illustrations)
- Ovals from 11_Ovals/ (12 approved ovals)
- Sketches from 13_Sketches/ (11 approved sketches)

✅ **Images must be:**
- Brand-compliant (no competitor products, no logo confusion)
- High resolution (1920×1080 minimum)
- Professional quality
- Diverse representation (if people imagery)

❌ **Never use:**
- Stock images that look generic/dated
- Images with competitors' products
- Non-diverse imagery
- Watermarked images

**See 30_Slide_Image_Showcase.md** for detailed image placement rules.

---

## STEP 6: ADD DATA/CHARTS

**Integrate all data visualizations.**

**Chart Types (approved):**
- Line charts (trends over time)
- Bar charts (comparisons)
- Pie charts (proportions)
- Process flows (steps/timeline)
- Custom infographics

**Rules:**
- Max 3-4 colors per chart
- All axes labeled
- Source cited
- 4.5:1 contrast minimum
- Never data alone (always paired with insight/title)

**See 29_Slide_Data_Chart.md** for detailed data visualization rules.

---

## STEP 7: REVIEW/QUALITY CHECK

**Before sending to client, run through quality checklist.**

**Review checklist:**

✅ **Content**
- All slides proofread (no typos)
- All key messages included
- Correct statistics/facts
- Tone consistent throughout

✅ **Design**
- One template used (no mixing)
- One color palette used (no random colors)
- All text readable (body 8–12pt, headlines 20–28pt)
- All text within safe area
- Logo position correct (right bottom or back-cover center)
- Margins and spacing consistent

✅ **Imagery**
- All images high-resolution
- All icons/illustrations from approved assets
- Images don't have watermarks
- No competitor products visible
- Diverse representation (if applicable)

✅ **Compliance**
- All text contrast meets 4.5:1 minimum
- No all-caps text
- Poppins font used (never substituted)
- CTA buttons follow spec (2-3 max per presentation)
- All CTAs have clear action (not vague)

✅ **Navigation**
- Slide order makes sense
- Flow from problem → solution → action
- Closing slide present
- No orphan slides (all slides serve a purpose)

**See 37_Quality_Checklist.md** for full checklist details.

---

## STEP 8: SEND TO CLIENT

**Prepare presentation for delivery.**

**File Setup:**
- Save as PowerPoint (.pptx)
- Filename: `[Client_Name]_SE_Presentation_[Date].pptx`
- Embed all fonts (Poppins TTF files)
- Test on different displays/projectors

**Delivery Package:**
- Main presentation file
- Optional: Speaker notes document
- Optional: Brand guidelines summary (for client reference)

**Final Check:**
- Open file on different machine (ensure fonts embedded)
- Test on projector (colors display correctly)
- Check animations/transitions (if any)

**Deliverable:** Client-ready presentation file.
