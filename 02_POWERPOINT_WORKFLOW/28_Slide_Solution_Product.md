# Slide: Solution/Product

**PowerPoint Workflow — Document 28**

---

## OVERVIEW

Solution/Product slides present the answer. They show how SE solves the problem or capitalizes on the opportunity.

**Purpose:** Position SE offering, highlight key benefits, create confidence in solution.

---

## CONTENT STRUCTURE

### HEADLINE
- **Text:** Solution or product name/statement
- **Font:** Poppins SemiBold, 18-20pt
- **Examples:**
  - "Our Integrated Energy Management Platform"
  - "The Power to Optimize"
  - "Three Key Capabilities"

### BODY CONTENT

**Option 1: Three Key Features/Benefits**
- Feature 1: Description (1-2 lines)
- Feature 2: Description (1-2 lines)
- Feature 3: Description (1-2 lines)

**Option 2: Solution Flow**
- Input → Process → Outcome
- (Icon/Illustration for each step)

**Option 3: Product Showcase**
- Product image (high-quality)
- Key specifications (3-4 bullets)
- Benefits summary

### VISUAL ELEMENTS
- Product image or illustration (recommended)
- Icons representing key features (optional)
- SE oval or accent shape (optional)
- Keep visual professional, not cluttered

### LAYOUT
- Headline at top
- 3 feature blocks or flows below (visual-heavy is good here)
- Maintain breathing room around visual

---

## BEST PRACTICES

### ✅ DO

- Lead with benefit, not feature
- Show how it solves the problem introduced earlier
- Use icons or illustrations to support features
- Focus on 3 key differentiators (max)
- Include product/solution image if available
- Make it visual (less text than problem slide)

### ❌ DON'T

- List 10+ features (too much)
- Use only text (solution slide should be visual)
- Forget to tie back to problem
- Oversell with hyperbole
- Use generic stock imagery
- Make it technical unless audience requires it

---

## COMMON MISTAKES & FIXES

| Mistake | Fix |
|---------|-----|
| Too many features (8+) | Focus on top 3 differentiators |
| No visual (text-only slide) | Add product image or illustration |
| Text is too technical | Translate tech-speak into benefits |
| Visual is low-quality | Use only professional imagery |
| Doesn't tie back to problem | Explicitly connect to problem slide |

---

## CHECKLIST

- ☐ Headline clearly states solution or product name
- ☐ 3 key features or benefits highlighted
- ☐ Each feature is 1-2 lines maximum
- ☐ Benefits clearly explained (not features alone)
- ☐ Visual element included (image, icon, or illustration)
- ☐ Visual is professional and high-quality
- ☐ All text uses template-correct color
- ☐ Font is Poppins, 12-14pt minimum
- ☐ Slide feels visual-forward (50%+ visual, 50%- text)
- ☐ Solution clearly addresses problem from previous slide
