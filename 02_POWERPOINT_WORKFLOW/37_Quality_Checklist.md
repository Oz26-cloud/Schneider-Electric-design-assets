# Quality Checklist

**PowerPoint Workflow — Document 37**

---

## PRE-SEND REVIEW

Before sending any presentation to client, run through this complete quality checklist.

This is your final gate. Nothing goes to client without passing all checks.

---

## SECTION 1: CONTENT

**Proofreading & Accuracy**

- ☐ All text is proofread (no typos, grammar errors)
- ☐ All statistics/numbers are verified and current
- ☐ All dates are correct
- ☐ Client name spelled correctly throughout
- ☐ No placeholder text remaining ("Lorem ipsum", "[INSERT]", "TODO")
- ☐ All slides serve a purpose (no orphan slides)
- ☐ Slide order makes logical sense (problem → solution → action)
- ☐ All slides flow naturally from one to next

**Message Alignment**

- ☐ All key messages from brief are included
- ☐ Each slide reinforces core message
- ☐ Data supports claims (nothing contradicts)
- ☐ No off-topic slides or tangents
- ☐ Conclusion ties back to opening

---

## SECTION 2: DESIGN CONSISTENCY

**Template & Colors**

- ☐ ONE template used throughout (no mixing white + dark green, etc.)
- ☐ All text colors match template specifications
- ☐ No custom colors invented (all from 05_Color_Palette.md)
- ☐ Background consistent (all slides use same template)
- ☐ No custom backgrounds replacing template

**Typography**

- ☐ Poppins font used exclusively (never substituted)
- ☐ Headline size consistent (18-22pt)
- ☐ Body copy size consistent (8–12pt)
- ☐ Line heights consistent (0.9 tight, 1.0 normal, 1.2 relaxed)
- ☐ No all-caps text (use Title Case or Sentence case)
- ☐ Font weights consistent (Regular for body, SemiBold for headers)
- ☐ Font embedding verified (will display correctly on other machines)

**Spacing & Layout**

- ☐ Margins consistent (0.51" left/right, 0.29" top, 0.18" bottom)
- ☐ All text within safe content area (not cut off at edges)
- ☐ Spacing between bullets consistent (0.4-0.5")
- ☐ White space used strategically (not cramped)
- ☐ Alignment consistent (left-aligned body text, centered titles)

**Logo & Branding**

- ☐ Logo in correct position (right bottom standard slides, middle-top back cover)
- ☐ Logo size locked by template (not manually resized)
- ☐ Logo color correct for template
- ☐ Tagline "Advancing Energy Tech" included (if applicable)
- ☐ All SE branding is current and approved

---

## SECTION 3: READABILITY & ACCESSIBILITY

**Text Contrast**

- ☐ All text is readable from 20 feet away
- ☐ Text contrast meets 4.5:1 minimum (WCAG AA standard)
- ☐ White template: headings in SE Dark Green (#0A2F24) or SE Signature Green (#009530); body text in SE Dark Green (#0A2F24)
- ☐ Dark Green template: White or Light Green text on dark green (high contrast)
- ☐ Light Green template: Dark Green text on light green (tested contrast)
- ☐ Gradient template: White or Electric Green text on gradient (4.5:1 verified)
- ☐ No red/green color-only differentiation (colorblind-friendly)

**Text Legibility**

- ☐ Headline minimum 18pt (readable from distance)
- ☐ Body copy is 8–12pt (10–12pt preferred)
- ☐ No body copy smaller than 8pt or larger than 12pt
- ☐ Bullet points are 2-3 lines maximum (not paragraphs)
- ☐ Maximum 5 bullet points per slide
- ☐ Line length not exceeding 8.98" (safe content area width)
- ☐ Text is not overlapping visuals in confusing ways

**Accessibility**

- ☐ No critical information conveyed by color alone
- ☐ All charts labeled (axes, legend, source cited)
- ☐ Alt text considered for image slides (if preparing for screen reader)
- ☐ No animations that distract or confuse
- ☐ Presentation is 16:9 aspect ratio (10" × 5.625")

---

## SECTION 4: IMAGERY & VISUALS

**Image Quality**

- ☐ All images are high resolution (1920×1080 minimum)
- ☐ No blurry, pixelated, or low-quality images
- ☐ No watermarks visible on any image
- ☐ No copyright issues (all images sourced from approved places)

**Image Source & Compliance**

- ☐ All images from GitHub repo → 04_ASSETS/ or SE-official sources
- ☐ No competitor products visible in images
- ☐ No competitor logos visible
- ☐ All images are brand-appropriate
- ☐ Image descriptions accurate (not misleading)

**Image Placement**

- ☐ Images support slide message (not decorative)
- ☐ Images are sized appropriately (not too small to see)
- ☐ Images within safe content area OR intentionally full-bleed
- ☐ Text overlay on images has 4.5:1 contrast minimum
- ☐ No images obscuring logo or footer

**Icons & Illustrations**

- ☐ All icons from GitHub repo → 04_ASSETS/14_Icons/ (571 approved only)
- ☐ All illustrations from GitHub repo → 04_ASSETS/16_Illustrations/ (196 approved only)
- ☐ No icons or illustrations are modified or redrawn
- ☐ Icon colors match approved palette (no custom colors)
- ☐ Icon sizes consistent within related groups
- ☐ Illustration sizing appropriate (not too small to see)

**Charts & Graphs**

- ☐ Chart type matches data type (line for trends, bar for comparison, etc.)
- ☐ Chart uses 3-4 colors maximum
- ☐ All axes labeled clearly
- ☐ Data values visible (not hidden)
- ☐ Source cited (company/study name and date)
- ☐ Key insight highlighted (callout, annotation, or supporting text)
- ☐ Chart readable from 20 feet away
- ☐ No misleading scaling (y-axis starts at 0, unless clearly justified)

---

## SECTION 5: BUTTONS & INTERACTIONS

**CTA Buttons**

- ☐ CTA button colors follow 09_CTA.md specifications
- ☐ CTA button text is action-oriented (Schedule, Request, Contact, etc.)
- ☐ CTA button text is 2-3 words maximum
- ☐ Maximum 2-3 CTA buttons per presentation
- ☐ Button contrast meets 4.5:1 minimum
- ☐ Button shape is capsule (rounded, not square)
- ☐ Button stroke is 1pt, 2mm corner radius

**Links & Navigation**

- ☐ All hyperlinks are tested and working
- ☐ All links open in correct window
- ☐ Links are obviously formatted (underlined or colored)

---

## SECTION 6: COMPLIANCE & BRAND RULES

**Brand Compliance**

- ☐ SE logo is never modified (size, color, rotation locked by template)
- ☐ No unapproved brand colors used
- ☐ Poppins font is ONLY approved typeface (never substituted)
- ☐ All slide dimensions are 10" × 5.625" (16:9)
- ☐ Footer area maintained (0.18" reserved for copyright + page number)
- ☐ Header area (top 0.29") used only for template design

**Template Rules**

- ☐ Template choice is locked (no mid-deck template changes)
- ☐ Template design is not customized or overridden
- ☐ Master slide layout is maintained (no custom backgrounds)
- ☐ Logo position is locked to template (right bottom or back-cover center)

**Gradient Template Rules (if applicable)**

- ☐ Gradient applied to ALL slides (not just some)
- ☐ Text contrast on gradient verified (4.5:1 minimum)
- ☐ No competing visuals with gradient
- ☐ Large venue assumption (gradient is designed for visibility from distance)

---

## SECTION 7: TECHNICAL

**File Setup**

- ☐ File saved as PowerPoint (.pptx)
- ☐ Filename is professional: [Client_Name]_SE_Presentation_[Date].pptx
- ☐ All fonts embedded (Poppins TTF files packaged)
- ☐ No external links or missing files
- ☐ File is not marked as "Read Only"

**Testing**

- ☐ File opens correctly on Windows and Mac
- ☐ File tested on different computer (fonts display correctly)
- ☐ Presentation tested on projector (colors accurate)
- ☐ Slideshow mode tested (no display errors)
- ☐ No missing or broken media files
- ☐ File size reasonable (under 100MB)

**Animation & Transitions (if used)**

- ☐ Animations are minimal and professional
- ☐ Slide transitions are consistent (same transition throughout)
- ☐ Animations don't distract from message
- ☐ Presenter can advance slides manually

---

## SECTION 8: FINAL REVIEW

**Workflow Check**

- ☐ All 8-step workflow phases completed (Brief → Outline → Template → Build → Imagery → Data → Review → Send)
- ☐ Client brief requirements all addressed
- ☐ Presentation length matches time constraint
- ☐ Slide count is appropriate (typically 10-25 slides)

**Stakeholder Sign-Off**

- ☐ Internal team review completed (if required)
- ☐ Client review completed (if pre-approval cycle exists)
- ☐ All feedback incorporated
- ☐ Final version approved before sending

**One Final Read-Through**

- ☐ Open presentation in slideshow mode
- ☐ View full presentation start to finish
- ☐ No jarring transitions or errors noticed
- ☐ Message flows logically
- ☐ Presentation feels professional and on-brand
- ☐ You're confident sending this to client

---

## QUICK CHECKLIST (Print & Post)

**Before opening PowerPoint:**
- ☐ Brief received and understood
- ☐ Template decided

**During design:**
- ☐ Every 3-4 slides: Review for consistency
- ☐ Every 5 slides: Check contrast and readability
- ☐ Before imagery: Verify image source (approved assets only)
- ☐ Before data: Chart type matches data

**Before sending:**
- ☐ Entire presentation proofread
- ☐ Quality checklist completed (all boxes checked)
- ☐ File tested on different computer
- ☐ Tested in slideshow mode
- ☐ Final review: "Is this presentation I'm proud of?"

---

## IF SOMETHING FAILS THIS CHECKLIST

**Do NOT send the presentation yet.**

2. Find related document (35, 36, 25-34, etc.)
3. Fix the issue
4. Re-check that section
5. Then send
