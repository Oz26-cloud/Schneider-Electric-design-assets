# Slide: Process/Timeline

**PowerPoint Workflow — Document 31**

---

## OVERVIEW

Process/Timeline slides show progression. They illustrate steps, phases, or sequence of events.

**Purpose:** Clarify workflow, show roadmap, demonstrate phased approach.

---

## LAYOUT OPTIONS

**Option 1: Linear Process (Left to Right)**
```
Step 1 → Step 2 → Step 3 → Step 4
(Icon)   (Icon)   (Icon)   (Icon)
```

**Option 2: Vertical Timeline**
```
Q1: Phase 1
Q2: PowerPoint Workflow
Q3: Phase 3
Q4: Phase 4
```

**Option 3: Numbered Boxes**
```
┌─────────┐  ┌─────────┐  ┌─────────┐
│ Step 1  │  │ Step 2  │  │ Step 3  │
│ Details │  │ Details │  │ Details │
└─────────┘  └─────────┘  └─────────┘
```

**Option 4: Circular/Cyclical**
```
    [Step 1]
   /        \
[Step 4]  [Step 2]
   \        /
    [Step 3]
```

---

## CONTENT STRUCTURE

### HEADLINE
- **Text:** Process name or timeline label
- **Font:** Poppins SemiBold, 16-18pt
- **Examples:**
  - "Implementation Timeline"
  - "Our Four-Phase Approach"
  - "Project Roadmap: 2024-2026"

### PROCESS/TIMELINE ELEMENTS
- **Number of steps:** 3-5 steps maximum
- **Per step:** Title (2-4 words) + brief description (1 line)
- **Font:** Poppins Regular, 12-14pt
- **Connector:** Arrow or line between steps

### VISUAL ELEMENTS
- **Icons:** One icon per step (from GitHub repo → 04_ASSETS/14_Icons/)
- **Colors:** Use SE greens, keep consistent
- **Timing labels:** If timeline, include dates (Q1, Q2, etc.)
- **Emphasis:** Highlight current step or critical milestone (optional)

---

## BEST PRACTICES

### ✅ DO

- Use 3-5 steps (not more)
- Add icons to visualize each step
- Use arrow or connector between steps
- Include timeline if relevant (dates, quarters)
- Make flow left-to-right or top-to-bottom
- Use consistent styling for each step

### ❌ DON'T

- Use more than 5 steps
- Mix visual directions (diagonal, zigzag)
- Include too much text per step
- Use unrelated icons
- Forget connectors (looks disconnected)
- Use colors outside approved palette

---

## COMMON MISTAKES & FIXES

| Mistake | Fix |
|---------|-----|
| Too many steps (7+) | Limit to 3-5, group related steps |
| Text too small (11pt) | Minimum 12pt, better 14pt |
| No icons or visual | Add one icon per step from GitHub repo → 04_ASSETS/ |
| Steps feel disconnected | Add arrows or lines between steps |
| Inconsistent styling | All steps same size, color, format |
