## 🎨 KEY SPECIFICATIONS AT A GLANCE

### COLOR SYSTEM
**6 Primary Colors:**
- SE Life Green (#3DCD58)
- SE Dark Green (#0A2F24)
- SE Signature Green (#009530)
- SE Electric Green (#5EFF59)
- SE Light Green (#E7FFD9)
- SE Light Gray (#FAFAFA)

**4 Secondary Colors (accents only):**
- SE Amber (#FFCE00)
- SE Cyan (#24F0FF)
- SE Blue (#2040FF)
- SE Red (#FF0050)

### TYPOGRAPHY
**Typeface:** Poppins (9 weights, each in upright and italic: 18 font files)
- Thin (100), ExtraLight (200), Light (300) — Captions; Thin and ExtraLight display only
- Regular (400) — Body, headings
- Medium (500) — Subheadings
- SemiBold (600) — Section titles
- Bold (700) — Emphasis (sparingly)
- ExtraBold (800), Black (900) — Display only

**Font sizes:** 6pt to 22pt (7 levels)
**Line heights:** 0.9 (tight), 1.0 (normal), 1.2 (relaxed)

### LOGO PLACEMENT (FIXED)
- **Standard slides:** Right bottom corner
- **Back cover:** Middle, towards top
- **Color:** SE Signature Green, Dark Green, Life Green, Electric Green, or White
- **Size/spacing:** Automatically handled by master slide

### SLIDE DIMENSIONS
- **Size:** 10.0" × 5.625" (16:9)
- **Safe area:** 8.98" wide × 5.155" tall
- **Margins:** Left/Right 0.51", Top 0.29", Bottom 0.18"

### GRADIENTS (4 Approved)
1. Diagonal TL-BR: Life Green → Dark Green
2. Horizontal L-R: Life Green → Signature Green
3. Vertical T-B: Signature Green → Dark Green
4. Diagonal TR-BL: Life Green → Electric Green

## ✅ COMPLIANCE CHECKLIST

Before sharing any presentation:

- ✅ One template selected (not mixed)
- ✅ Using approved Poppins font (never substitute)
- ✅ Colors from approved palette only
- ✅ Logo in correct position (right bottom or back-cover center)
- ✅ All text meets 4.5:1 contrast ratio minimum
- ✅ No all-caps text
- ✅ Icons from 14_Icons/ folder only
- ✅ Illustrations from 16_Illustrations/ folder only
- ✅ Sketches at max 50% opacity if used
- ✅ CTA buttons follow 09_CTA.md specification
- ✅ Margins and safe zones respected
- ✅ Presentation reviewed on actual projector
