# Typography Fonts

**Phase 1A Foundation Layer — Document 6**

---

## APPROVED TYPEFACE

**Poppins** is the ONLY approved typeface for Schneider Electric PowerPoint presentations.

Never substitute with alternative fonts.

---

## FONT WEIGHTS

Poppins has 9 weights, each available in upright and italic (18 font files in the repo).

| Weight | Value | Usage |
|--------|-------|-------|
| Thin | 100 | Display only, not for body text |
| ExtraLight | 200 | Display only, not for body text |
| Light | 300 | Taglines and captions |
| Regular | 400 | Body text |
| Medium | 500 | Subheadings, section headers |
| SemiBold | 600 | Headings and section titles |
| Bold | 700 | Key word emphasis only (sparingly) |
| ExtraBold | 800 | Display only, not for body text |
| Black | 900 | Display only, not for body text |

Italic versions exist for every weight (for example Poppins-LightItalic.ttf, Poppins-BoldItalic.ttf).

---

## FONT SIZES

| Size | Points | Usage |
|------|--------|-------|
| 3XL | 22pt | Largest title size |
| 2XL | 18pt | Large header |
| XL | 16pt | Section header |
| LG | 14pt | Large body |
| Base | 10pt | Body text (smallest size for body) |
| SM | 8pt | Small/caption |
| XS | 6pt | Fine print |

---

## LINE HEIGHTS

| Value | Name | Usage |
|-------|------|-------|
| 0.9 | Tight | Headers, titles (H1, H2, H3) |
| 1.0 | Normal | Body text, paragraphs (default) |
| 1.2 | Relaxed | Long-form content, accessibility |

---

## TYPOGRAPHY RULES

- **Never use all caps** — Use Title Case or Sentence case
- **Bold sparingly** — key word emphasis only. Use SemiBold for headings
- **No text under 10pt.**
- **Slide text rules** (line length, sizes on slides, bullets): see `02_POWERPOINT_WORKFLOW/22_Slide_Setup.md`
