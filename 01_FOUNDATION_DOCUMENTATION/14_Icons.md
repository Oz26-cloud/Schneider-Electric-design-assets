## OVERVIEW

This document specifies icon and pictogram usage for Schneider Electric PowerPoint presentations. Icons communicate concepts visually, improve scannability, and enhance professional appearance.

**Core Principle:** Icons clarify content, guide reader attention, and reinforce key messages without cluttering slides.

## ICON STYLE CHARACTERISTICS

### Visual Style

**Approved icon style:**
- ✅ Simple, geometric shapes
- ✅ Consistent line weight
- ✅ Clear, immediately recognizable
- ✅ Modern, contemporary design
- ✅ Minimal detail (not photorealistic)
- ✅ Uniform style across library
- ✅ 24-32px baseline design size

**Avoid:**
- ❌ Overly complex, detailed icons
- ❌ Photorealistic imagery
- ❌ Inconsistent style (mixing sources)
- ❌ Outdated or retro design
- ❌ 3D or shadowed effects
- ❌ Thin, barely-visible lines

## ICON COLOR PALETTE

Icons use PRIMARY brand colors:

**Approved colors for icons:**
- SE Life Green (#3DCD58) — Primary action/emphasis
- SE Signature Green (#009530) — Standard/secondary
- SE Dark Green (#0A2F24) — Outlines, dark elements
- SE Light Green (#E7FFD9) — Light fills, disabled state
- SE Electric Green (#5EFF59) — High emphasis, alerts
- White (#FFFFFF) — Reverse on dark backgrounds
- Dark Green — Neutral/default

**Color approach:**
- Single color per icon (typically)
- Icons designed in brand colors
- Can be recolored to match slide context
- Monochromatic or simple two-tone

**❌ NOT APPROVED:** Secondary accent colors (Amber, Cyan, Blue, Red) are NOT used for standard icons.

## ICON SIZING

### Standard Icon Sizes

| Size | Width/Height | Use Case | Context |
|------|--------------|----------|---------|
| **Extra Large** | 1.5" - 2.0" | Major visual accent | Primary icon on slide |
| **Large** | 1.0" - 1.5" | Standard icon use | Prominent placement |
| **Medium** | 0.5" - 1.0" | Bullet point alternative | List item icon |
| **Small** | 0.25" - 0.5" | Inline icon | Text-integrated icon |
| **Extra Small** | 0.125" - 0.25" | Minimal accent | Fine detail |

**Guidelines:**
- Icons remain recognizable at size used
- Minimum size ~0.25" (smaller loses legibility)
- Scale proportionally (icons are square)
- Maintain consistent sizing in icon series

## ICON USAGE CONTEXTS

### As Bullet Point Replacements

**Replace traditional bullets with icons:**
- ✅ Improves visual interest
- ✅ Aids content scannability
- ✅ Reinforces key concepts
- ✅ More engaging than text alone

**Guidelines:**
- Choose icon that represents concept
- All bullets in list use similar icon size
- Icons aligned consistently
- Text flows naturally from icon

---

### As Visual Callouts

**Icons to highlight important information:**
- ✅ Feature highlights
- ✅ Key benefits
- ✅ Warning or alert
- ✅ Success or checkmark

**Guidelines:**
- Icon size medium to large
- Clear visual hierarchy
- Icon precedes or above text
- Label text concise and clear

---

### In Process Flows

**Icons representing steps or stages:**
- ✅ Number or status progression
- ✅ Decision points or branches
- ✅ Input/output or transformation
- ✅ Start/end points

**Guidelines:**
- Consistent icon sizing across flow
- Arrows or connectors between steps
- Labels for each step or stage
- Left-to-right or top-to-bottom progression

---

### As Data Visualization

**Icons representing data categories:**
- ✅ Chart legends
- ✅ Data grouping
- ✅ Category identification
- ✅ Metric labeling

**Guidelines:**
- Small to medium icon size
- Consistent styling with chart
- Legend clarity
- Color-coded if applicable

## ICON PLACEMENT

### Positioning Guidelines

**Icons can be placed:**
- ✅ Beside text (left or right aligned)
- ✅ Above text (centered or left)
- ✅ Inline with text (inline sizing)
- ✅ Corner or edge (decorative accent)
- ✅ Full-slide pattern (background texture)

**Typical placements:**

| Placement | Text Position | Icon Size | Use Case |
|-----------|---------------|-----------|----------|
| **Left of text** | Flows right from icon | Small-Medium | Bullet list, features |
| **Above text** | Centered below icon | Medium-Large | Feature callout, step |
| **Inline** | Text wraps around | Small | Inline emphasis |
| **Corner** | Independent of text | Small | Decorative, accent |
| **Full pattern** | Over pattern | Extra Small | Subtle background |

## ICON ACCESSIBILITY

### Alt Text for Icons

When icons appear as visual content (not just decorative):
- ✅ Descriptive alt text (for screen readers)
- ✅ Describes icon meaning in context
- ✅ Brief but clear (1-2 sentences)

**Examples:**
- ✅ "Solar panel icon representing renewable energy"
- ✅ "Checkmark indicating complete or approved status"
- ✅ "People icon representing team or collaboration"

**Avoid:**
- ❌ "Icon" or "Image"
- ❌ Over-detailed descriptions
- ❌ Redundant if text already explains

### Icon Contrast

**If icon appears on colored background:**
- Ensure sufficient contrast (minimum 3:1)
- Light icon on dark background
- Dark icon on light background
- Test before finalizing

### Icon Clarity

Icons must be:
- ✅ Immediately recognizable at size used
- ✅ Clear meaning without extensive explanation
- ✅ Intuitive or labeled for clarity

## ICON WORKFLOW FOR POWERPOINT

### Step 1: Identify Content Needing Visual Support

What information benefits from visual representation?
- Bullet points or feature list?
- Process or workflow steps?
- Data categories or grouping?
- Alert, warning, or important callout?

### Step 2: Select Appropriate Icon

From 571-icon library, find best match:
- Represents concept accurately
- Style matches presentation aesthetic
- Appropriate level of detail
- Color works with slide design

### Step 3: Determine Placement

**Where will icon sit on slide?**
- Beside text (supporting)
- Above text (introducing)
- Inline (flowing with text)
- Corner/edge (accent)

### Step 4: Size Icon Appropriately

- List bullets: Small-Medium (0.25" - 0.75")
- Feature callout: Medium-Large (0.75" - 1.5")
- Full-slide accent: Large (1.0" - 2.0")
- Inline: Small (0.125" - 0.25")

### Step 5: Position on Slide

- Align with content
- Maintain consistent spacing
- Respect safe content area
- Test on projected display

### Step 6: Choose Color

- Use icon as designed (default)
- OR recolor to match template
- Ensure sufficient contrast on background
- Maintain consistency across related icons

### Step 7: Add Supporting Text

- Label icon if meaning unclear
- Concise, clear accompanying text
- Icon supports text, not vice versa
- Test readability together

## ICON USAGE EXAMPLES

### Example 1: Feature List with Icons

**Scenario:** Highlighting three key benefits

**Icon approach:**
- Three icons (one per feature)
- Medium size (0.75" - 1.0")
- Left-aligned with text flowing right
- All icons same color and size
- Brief feature name/description per icon

---

### Example 2: Process Flow

**Scenario:** Four-step workflow or journey

**Icon approach:**
- Four sequential icons
- Medium size (0.75" - 1.0")
- Connected with arrows or lines
- Numbered or labeled steps
- Brief description per step

---

### Example 3: Alert or Warning

**Scenario:** Important notice or attention-getter

**Icon approach:**
- Single large icon (1.5" - 2.0")
- Eye-catching color (Electric Green or Life Green)
- Centered on slide
- Text below or beside
- Clear, actionable messaging

---

### Example 4: Data Categories

**Scenario:** Chart legend with categories

**Icon approach:**
- Small icons (0.3" - 0.5")
- Next to category labels
- Color-coded or consistent
- Legend clarity

## WHEN TO USE ICONS

### Use Icons When:

- ✅ Improving content scannability
- ✅ Visual representation clarifies concept
- ✅ Enhancing bullet points or lists
- ✅ Breaking up text-heavy content
- ✅ Identifying key information
- ✅ Supporting process or workflow visualization
- ✅ Reinforcing brand visual language

### Avoid Icons When:

- ❌ Icon meaning unclear or confusing
- ❌ Slide already visually complex
- ❌ Icon adds no informational value
- ❌ Overcrowding slide with too many icons
- ❌ Icon might distract from main message
- ❌ Unable to represent concept clearly with available icons
