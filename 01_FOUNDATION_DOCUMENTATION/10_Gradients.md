# Schneider Electric Gradients

**Phase 1A Foundation Layer — Document 10**

---

## OVERVIEW

This document specifies all approved gradient backgrounds for Schneider Electric PowerPoint presentations. Gradients add visual depth, energy, and modern aesthetic while maintaining brand consistency.

**Core Principle:** Gradients enhance visual impact without compromising readability or brand recognition.

---

## GRADIENT PHILOSOPHY

### When to Use Gradients

Gradients work best for:
- ✅ Title/cover slides
- ✅ Section break slides
- ✅ High-impact brand moments
- ✅ Premium executive presentations
- ✅ Visual contrast against text-heavy slides

**Do NOT use gradients for:**
- ❌ Slides with dense body text (reduces readability)
- ❌ Charts or data visualizations (distracting background)
- ❌ Slides with many images (competing visual elements)

## GRADIENT USAGE BEST PRACTICES

### ✅ DO

- ✅ Test text legibility on actual gradient before finalizing
- ✅ Use gradient background as template master (not manual addition)
- ✅ Limit gradients to title and transition slides
- ✅ Ensure sufficient contrast for all text on gradient
- ✅ Keep content minimal on gradient backgrounds (focus on message)
- ✅ Use consistent gradient direction across presentation
- ✅ Test gradient on projected display for color accuracy

### ❌ DON'T

- ❌ Layer multiple gradients on same slide
- ❌ Mix gradient with pattern or image background
- ❌ Use gradients with dense text content (hard to read)
- ❌ Apply gradient only to individual slides (use template instead)
- ❌ Use colors outside approved gradient palette
- ❌ Place white or light text on light portions of gradient without testing
- ❌ Use gradients on every slide (visual fatigue)

## GRADIENT WITH TEXT OVERLAY

### Text Placement on Gradients

**Optimal placement:**
- **Title:** Center of slide, largest contrast area
- **Subtitle:** Below title, ensure readability
- **Body text:** Minimal on gradient (better on solid color slide below)

### Text Color Selection on Gradients

**Test contrast for legibility:**

| Gradient | Light text area | Dark text area |
|----------|-----------------|-----------------|
| Gradient 1 (Life→Dark Green) | Start (top-left) | End (bottom-right) |
| Gradient 2 (Life→Signature) | Start (left) | End (right) |
| Gradient 3 (Signature→Dark) | Start (top) | End (bottom) |
| Gradient 4 (Life→Electric) | Variable | Variable |

**Guidance:**
- Place light text (white) on darker gradient areas
- Place dark text (Dark Green) on lighter gradient areas
- Test on actual slide before finalizing
- Use semi-transparent overlays if contrast insufficient

---

## GRADIENT WITH IMAGES

### Image Placement on Gradient Backgrounds

Images can:
- ✅ Extend over entire gradient (full-bleed)
- ✅ Overlap gradient with images
- ✅ Use gradient as frame for images

**Best practices:**
- Ensure image maintains focal point clarity
- Add semi-transparent overlay if image competes with gradient
- Test image visibility on projected display
- Keep images within safe content area OR use full-bleed intentionally

---

## GRADIENT WITH LOGO

### Logo Placement on Gradients

**Logo positioning:** Fixed in master slide (see Document 7: 07_Logo.md.md)

**Logo color on Gradient 1-3:** White (#FFFFFF)
- Highest contrast, most legible
- Test on actual gradient for visibility

**Logo color on Gradient 4:** White (#FFFFFF) or SE Dark Green (#0A2F24)
- Gradient 4 is very bright (Electric Green)
- May require Dark Green for sufficient contrast
- Test both options on actual background

**Requirements:**
- Verify contrast ratio (minimum 4.5:1)
- Test on projected screen for visibility
- Maintain logo size from master slide (no adjustments)

## ACCESSIBILITY REQUIREMENTS

### Contrast Ratios

**Text on gradients must meet WCAG standards:**

- **Body text:** Minimum 4.5:1 contrast ratio (WCAG AA)
- **Large text (18pt+):** Minimum 3:1 contrast ratio (WCAG AA)

**Testing gradient contrast:**
1. Measure contrast at lightest area of gradient
2. Measure contrast at darkest area of gradient
3. Ensure minimum standard met in both areas
4. Test actual text placement on final gradient

### Color Blindness Considerations

Gradients should not rely solely on color differentiation:
- ✅ Use value (brightness) variation for clarity
- ✅ Add texture or pattern if color alone insufficient
- ✅ Test gradients in grayscale to verify visibility

### Testing Tools

Use online tools to verify gradient contrast:
- WebAIM Contrast Checker (for specific points)
- Accessibility validators (for overall slide)
- Color blindness simulators (for universal design)

## GRADIENT WORKFLOW FOR POWERPOINT

### Step 1: Decide if Gradient Needed

Is this a:
- ✅ Title slide? (use gradient)
- ✅ Section break? (consider gradient)
- ✅ High-impact moment? (use gradient)
- ❌ Dense content slide? (use solid background)
- ❌ Chart/data slide? (use solid background)

### Step 2: Choose Gradient Type

| Message | Best Gradient |
|---------|---------------|
| **Energetic opening** | Gradient 1 (Life → Dark) |
| **Professional flow** | Gradient 2 (Life → Signature) |
| **Executive authority** | Gradient 3 (Signature → Dark) |
| **Innovation/cutting-edge** | Gradient 4 (Life → Electric) |

### Step 3: Select Gradient Template

- Use AET_Template_-_gradient.pptx
- Template automatically applies chosen gradient to all slides
- Logo color and positioning already set

### Step 4: Plan Text Content

- Minimal text on gradient (focus on clarity)
- Title + subtitle optimal; avoid body text on gradient
- Verify text color contrast (white or Dark Green)
- Test on projected display

### Step 5: Verify Accessibility

- ✅ Test contrast ratio on actual gradient
- ✅ Ensure legibility in presentation room lighting
- ✅ Verify on multiple devices (laptop, projector)
- ✅ Test keyboard navigation (if interactive elements)
