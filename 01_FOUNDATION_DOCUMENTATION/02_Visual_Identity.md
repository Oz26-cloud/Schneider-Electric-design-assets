# Visual Identity

**Phase 1A Foundation Layer — Document 2**

---

## OVERVIEW

Visual identity defines how Schneider Electric appears across all brand materials, including presentations. This document establishes the visual principles, design elements, and composition approaches that make presentations instantly recognizable.

---

## CORE VISUAL PRINCIPLES

### Modular Design
- Flexible layouts that adapt to content
- Consistent spacing and proportions
- Scalable elements

### Organic Geometry
- Flowing curves and ovals
- Natural, fluid movement
- Soft rounded corners

### Color-Driven
- Bold use of primary greens
- Strategic accent colors
- High contrast for readability

### Modern & Professional
- Clean, minimalist aesthetic
- Contemporary typography
- Professional imagery

## COMPOSITION APPROACH

### Balance
- Symmetrical for formal messages
- Asymmetrical for dynamic content
- White space strategically used

### Hierarchy
- Primary information dominates
- Supporting details secondary
- Visual weight supports message

### Flow
- Top-to-bottom reading pattern
- Left-to-right movement
- Clear navigation through content
