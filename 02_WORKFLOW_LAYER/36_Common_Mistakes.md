## 7 MISTAKES TO AVOID

The most common design errors in SE presentations, and how to fix them.

---

## MISTAKE 1: WRONG COLORS USED

**What happens:** Text is hard to read, colors don't match brand palette, presentation looks unprofessional.

**Why it happens:**
- Designer invents new colors instead of using palette
- Confusion about which colors work on which template
- Copying colors from non-SE sources

**How to fix:**
- ✅ ONLY use colors from 05_Color_Palette.md
- ✅ Check template-specific color rules (see 24_Template_Selection_Guide.md)
- ✅ Test contrast ratio (must be 4.5:1 minimum)
- ✅ When in doubt, use template's primary color for headlines

**Prevention:** Pin color palette to your desktop. Never guess.

---

## MISTAKE 2: TEXT TOO SMALL

**What happens:** Audience can't read from more than a few feet away, presentation loses impact, looks amateur.

**Why it happens:**
- Designer tries to fit too much text on slide
- Using headline size from different presentation system
- Not testing readability from distance

**How to fix:**
- ✅ Minimum headline: 18pt (better: 20-22pt)
- ✅ Minimum body text: 10pt (better: 12-14pt)
- ✅ Test from 20 feet away before submitting
- ✅ If text doesn't fit in size limits, cut content

**Prevention:** "If I can't read it from 20 feet, it's too small."

---

## MISTAKE 3: TOO MUCH TEXT ON SLIDE

**What happens:** Slide becomes wall of text, audience stops reading, message gets lost, looks cluttered.

**Why it happens:**
- Designer copies full paragraphs instead of summarizing
- Including all details when only main points needed
- Not trusting audience to listen to speaker

**How to fix:**
- ✅ Maximum 5 bullet points per slide (better: 3-4)
- ✅ Maximum 2-3 lines of text per bullet
- ✅ Convert full sentences to short phrases
- ✅ Cut by 50% — if it doesn't fit, it's too much

**Prevention:** Fewer words = more powerful. The slide supports the speaker; the speaker isn't reading the slide.

---

## MISTAKE 4: WRONG TEMPLATE CHOSEN

**What happens:** Presentation tone doesn't match audience or message, undermines credibility, feels inconsistent.

**Why it happens:**
- Designer didn't follow decision tree
- Template chosen for personal preference, not audience
- Last-minute template change mid-deck (mixing templates)

**How to fix:**
- ✅ Use 24_Template_Selection_Guide.md BEFORE designing
- ✅ Lock template choice in Step 3 of workflow
- ✅ Never mix templates in same presentation
- ✅ If wrong template chosen, redesign entire deck (don't try to fix mid-stream)

**Prevention:** Template choice should take 2 minutes, not 2 hours. Use the decision tree.

---

## MISTAKE 5: LOGO PLACED INCORRECTLY

**What happens:** Logo is moved from template position, presentation looks amateurish, brand consistency broken.

**Why it happens:**
- Designer doesn't know logo is locked in template
- Trying to "customize" logo position
- Misunderstanding template master slide

**How to fix:**
- ✅ Logo position is LOCKED in template master slide
- ✅ Logo placement: Right bottom corner (standard slides) or middle-top (back cover)
- ✅ NEVER move, resize, or recolor logo manually
- ✅ If logo position needs adjustment, change template master, not individual slide

**Prevention:** "Logo position is untouchable. It's locked for a reason."

---

## MISTAKE 6: IMAGES NOT BRAND-COMPLIANT

**What happens:** Competitor products visible, generic stock photos used, watermarks appear, presentation looks unprofessional.

**Why it happens:**
- Using Google Images or generic stock
- Not checking image source
- Accepting client image without vetting
- Watermarks not removed before inserting

**How to fix:**
- ✅ ONLY use images from GitHub repo → 04_ASSETS/ or SE-official sources
- ✅ Check for competitor logos/products in image
- ✅ Verify image resolution is 1920×1080+ minimum
- ✅ Remove all watermarks before placing
- ✅ If unsure about image, don't use it

**Prevention:** "If it's not from GitHub repo → 04_ASSETS/ or SE-official, I'm not using it."

---

## MISTAKE 7: INCONSISTENT LAYOUTS

**What happens:** Each slide looks different, presentation feels disjointed, audience loses confidence in brand.

**Why it happens:**
- Different designers working on same deck
- Not following slide-type guides (25-34)
- Changing spacing, alignment, or color between slides
- Not using template consistently

**How to fix:**
- ✅ One designer per presentation (when possible)
- ✅ Follow slide-type guides for each slide type
- ✅ Use template throughout (no custom backgrounds)
- ✅ Keep spacing consistent (0.4-0.5" margins)
- ✅ Use same headline treatment on all similar slides
- ✅ Review every 3-4 slides for consistency

**Prevention:** "Every title slide should look like every other title slide."

## PREVENTION CHECKLIST

Before submitting ANY presentation:

| Mistake | Check | Fix |
|---------|-------|-----|
| Wrong colors? | All colors from 05_Color_Palette.md | Replace non-approved colors |
| Text too small? | Headlines 18pt+, body 10pt+ | Increase font sizes |
| Too much text? | Max 5 bullets, 2-3 lines each | Cut content by 50% |
| Wrong template? | Template matches audience/topic | Redesign in correct template |
| Logo moved? | Logo in right bottom (standard) | Reset to template position |
| Non-compliant image? | Image from GitHub repo → 04_ASSETS/ only | Replace with approved image |
| Inconsistent layouts? | Same slide types match each other | Standardize all similar slides |

## QUICK FIX WORKFLOW

If you catch a mistake during design:

1. **STOP** — Don't submit the presentation
2. **IDENTIFY** — Which mistake is it?
3. **FIX** — Use the "How to fix" section above
4. **VERIFY** — Run through checklist again
5. **SUBMIT** — Now it's ready
