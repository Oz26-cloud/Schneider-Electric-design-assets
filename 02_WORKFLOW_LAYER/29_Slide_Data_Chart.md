# Slide: Data/Chart

**Phase 2 Workflow Layer — Document 29**

---

## OVERVIEW

Data/Chart slides provide proof. They show results, trends, comparisons, or outcomes using visualization.

**Purpose:** Build credibility through evidence, prove solution effectiveness, quantify benefits.

---

## CHART TYPES

**Line Chart** — Trends over time (growth, improvement, decline)
**Bar Chart** — Comparisons, rankings, or categories
**Pie Chart** — Proportions or percentages
**Table** — Structured comparison of metrics
**Custom Infographic** — Specific data visualization

---

## CONTENT STRUCTURE

### HEADLINE
- **Text:** Data insight or result statement
- **Font:** Poppins SemiBold, 16-18pt
- **Examples:**
  - "Energy Costs Reduced by 30% in Year One"
  - "Performance Metrics: 2024 vs. 2025"
  - "Regional Adoption Growth"

### CHART/VISUALIZATION
- **Size:** Take up 60-70% of slide space
- **Type:** Line, bar, pie, or custom infographic
- **Colors:** Max 3-4 colors (use SE greens + 1 accent)
- **Quality:** High resolution, professional styling
- **Labels:** All axes labeled, data points clear

### SUPPORTING TEXT
- **Insight/Callout:** 1-2 sentences explaining chart
- **Font:** Poppins Regular, 11-13pt
- **Placement:** Below chart or in corner callout box
- **Purpose:** Highlight key finding, not repeat chart data

### SOURCE CITATION
- **Text:** "Source: [Company/Study]"
- **Font:** Poppins Light, 9pt
- **Placement:** Bottom corner, subdued color

---

## BEST PRACTICES

### ✅ DO

- Choose chart type that best shows data
- Label axes clearly
- Use 3-4 colors maximum
- Cite data source
- Highlight key insight (callout or annotation)
- Make chart readable from 20 feet away
- Use SE greens as primary colors

### ❌ DON'T

- Use more than 4 colors in one chart
- Crowd multiple charts on one slide
- Use 3D effects or decorative elements
- Show uncited data
- Make chart labels too small
- Use gradient background chart (hard to read)
- Misrepresent data with misleading scale

---

## DATA QUALITY RULES

- **Accuracy:** Verify all numbers before slide
- **Source:** Always cite source
- **Relevance:** Data must support presentation message
- **Timeliness:** Use current data (within 1-2 years)
- **Completeness:** Don't cherry-pick outlier data

---

## COMMON MISTAKES & FIXES

| Mistake | Fix |
|---------|-----|
| Chart is too small to read | Make chart 60-70% of slide |
| Multiple charts on one slide | Use one chart per slide only |
| Too many colors (5+) | Limit to 3-4 colors |
| Axis labels missing | Label all axes, data points |
| Chart doesn't match message | Ensure chart proves your point |
| No source cited | Always cite source, date |
