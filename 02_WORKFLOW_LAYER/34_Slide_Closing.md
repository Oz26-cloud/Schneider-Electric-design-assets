# Slide: Closing

**Phase 2 Workflow Layer — Document 34**

---

## OVERVIEW

The closing slide is the last impression. It reinforces key message and provides final contact.

**Purpose:** Summarize, thank audience, remind them of SE value, leave them with SE branding.

---

## CONTENT STRUCTURE

### HEADLINE
- **Text:** "Thank You", "Questions?", "Let's Connect", or similar
- **Font:** Poppins SemiBold, 20-22pt
- **Centered alignment**

### KEY TAKEAWAY (Optional)
- **Text:** 1-2 sentence summary of main message
- **Font:** Poppins Regular, 14-16pt
- **Purpose:** Remind audience of primary value

### CONTACT INFORMATION
- **Name:** Presenter name
- **Email:** Email address
- **Phone:** Phone number
- **Website:** Website URL
- **Social:** LinkedIn, if relevant
- **Font:** Poppins Regular, 12-14pt

### VISUAL ELEMENT
- SE tagline: "Advancing Energy Tech" (optional)
- Logo: Locked in template position
- Subtle graphic or color accent (optional)

---

## BEST PRACTICES

### ✅ DO

- Keep it simple and clean
- Include all contact methods
- Remind audience of tagline ("Advancing Energy Tech")
- Make contact info clearly readable
- Center align for formality
- End on positive, professional note

### ❌ DON'T

- Include too much text
- Leave contact info blank
- Use busy background or visuals
- End abruptly without thanks
- Forget logo position
- Use non-template colors

## COMMON MISTAKES & FIXES

| Mistake | Fix |
|---------|-----|
| No contact info provided | Include name, email, phone, website |
| Contact info too small (10pt) | Minimum 12pt, better 14pt |
| Tagline missing | Include "Advancing Energy Tech" |
| Too much text on slide | Keep it minimal and scannable |
| Logo position wrong | Ensure locked to template position |
